# Add a user friendly interface to browse the library

created
: 20261113

closed
: 20261113

The JSesh library used to be given as a separate folder. Currently, the user must "export" it to read it. It's useful, and should be kept, but it should be possible to browse the library directly from the software, without having to export it first. 

A text from the library, when loaded, would be seen as:

- a clean text (without changes, not asking to save it)
- a text without related file. I.e. if the user change it, and wants to save it, he will need to choose a file name.

The library navigation tool will contain a list of texts, with names taken from the first (actual) line of the text, a line of alphabetic text, usually in bold, or the file name if no such line is found. The list will be sorted alphabetically, and will contain a search field to filter the list.
