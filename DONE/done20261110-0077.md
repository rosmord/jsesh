# Add a mechanisme for uniform scaling of elements

created
: 20260726

closed
: 20261110

(reviewed) add something like `%hbox[nohscale]()` for things like `x*x:x`

Currently, we have two options to control quadrant layout:

- limit quadrat sizes to the quadrat width
- enlarge lone low broad signs

Selecting the first one has the side effect of making quadrat layout uniform, but it's really a side effect. And it doesn't limit quadrat width.

We should make a final decision before the actual release of the software.

## Update (2026-11-10)

The two concerns are now separate options: `honourmaxquadratwidth` (limit the width, on by default) and `uniformquadratscaling` (scale the whole quadrat with one scale, off by default); see "Quadrat scaling" in the technical glossary. What remains open is the per-element notation (`%hbox[nohscale]()`) for a single hbox.
