# BUG FIX

created
: 20261106

When editing a text containing a very wide zone with multiple columns:

- ~~the global width is wrong. At least, We don't have scrollbars to show the part on the right of the screen;~~
- ~~and the system which is supposed to move the view to the caret position is not working when we move to the right of the columns, outside of the current view.~~

Wrap view was true, and it doesn't work well with zones, in particular with columns.

Solution: **don't save wrap view in the preferences**. It is not a good idea to have it on by default, and it is not a good idea to have it on in the preferences.
