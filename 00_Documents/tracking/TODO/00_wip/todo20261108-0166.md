# Running variant and running lacuna

created
: 20261108

Add constructs to handle the old MdC constructs `^-..-..-^` (running variant/haplography) and `?-..-..-?` (running lacuna).

1. add a @haplography[] annotation, with a parameter `size`, which can be either `fill` or a size in percentages of quadrat. It will be drawn as an horizontal line (in horizontal text) or a vertical line (in vertical text) with two arrows at the ends (`<------------>`). In the case of `fill`, it will collaborate with tabs to fill the current cell.
2. add a @lacuna[] annotation, which will work in the same way, but with a dashed line instead of a solid line and no arrows.
3. add in the lexicon a construct which will reaad  `^-..-..-^`  and `?-..-..-?`  and transform them into the corresponding annotations. It will count dots to compute the size of the annotation, i.e. if n is the number of dots, the size will be (n/2)*100.0.
