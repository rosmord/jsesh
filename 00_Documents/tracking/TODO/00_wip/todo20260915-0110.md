# Notify users when they edit Manuel de Codage directly

created
: 20260915

The *manuel de codage* field on the bottom of the JSesh Window is there for legacy reasons. I still occasionally use it for a few constructs that have no dedicated user interface yet (tabs, alphabetic text editing....) but the whole JSesh UI is supposed to be WYSIWYG, with a friendly user interface and smooth typing, as described in the [tutorial](https://jsesh.qenherkhopeshef.org/tutorials/jsesh-101).

Thus, I still need people to be able to use this mdc field, especially because historical users of Winglyph are used to it, but I would like to notify users when they do so.

The best, non invasive way, would be to use the **message** field in the bottom of the JSesh Window, and to print, in friendly red letters, something like : typing the Manuel de Codage text is not the easiest way to use JSesh... please see the tutorial (and perhaps add somewhere a link to JSesh tutorial and documentation)

Source: https://github.com/rosmord/jsesh/issues/57 (issue #57)
