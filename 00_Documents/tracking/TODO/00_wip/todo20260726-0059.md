# Add circular enclosure

created
: 20260726

Add circular enclosure.

The original Manuel de Codage has a system for square enclosures, e.g. `<F-bA-A-y:r-Aa18:Z1-qmA->`, but in the case of foreign countries, we often meet circular enclosures with battlements.

The Rosette project (Euverte et al.) use the letter `G` for this purpose, and we have no reason to use another code. Hence, `<G-bA-A-y:r-Aa18:Z1-qmA->` should be a circular enclosure.
