# Add Macscribe spaces

created
: 20261106

Macscribe defined a number of useful spaces :

`.f`
: zero size-space which acts as filler. That is, `.f:A` will probably be the same as A, but `.f:t` will ensure the "t" occupies the lower part of the quadrat.

`.v`
: vertical space filler; zero width, but stretchable height;

`.h`
: horizontal space filler; zero height, but stretchable width.

They might be useful.
