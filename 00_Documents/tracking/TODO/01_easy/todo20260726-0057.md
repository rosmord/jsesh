# Define document dimensions

created
: 20260726

Define document dimensions.

Decided on 20261028, with `%zone`: the document is the outermost zone, and its settings live in the `++JSesh_…` header. A page is optional (by default a document is as large as its text): it is a width (or height) constraint on this root zone, plus margins and a displayed page frame. Automatic pagination comes later. The header keys `JSESH_PAGE_WIDTH/HEIGHT` and `TEXT_*` already exist in `JSeshInfoConstants`, unused.
