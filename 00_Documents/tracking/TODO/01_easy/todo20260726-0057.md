# Define document dimensions

created
: 20260726

Define document dimensions.

Decided on 20261028, with `%zone`: the document is the outermost zone, and its settings live in the `++JSesh_…` header. A page is optional (by default a document is as large as its text): it is a width (or height) constraint on this root zone, plus margins and a displayed page frame. Automatic pagination comes later. The header keys `JSESH_PAGE_WIDTH/HEIGHT` and `TEXT_*` already exist in `JSeshInfoConstants`, unused.

## Done 20261104 (first step)

- `PageSpecification` (page width/height, four margins; `NONE` = no page) in `GeometrySpecification.page`. With a page, lines wrap at its usable width (`GeometrySpecification.maxLineWidth()`); zones never inherit it.
- Saved in the header: `JSesh_page_width`, `JSesh_page_height`, `JSesh_page_margin_left/right/top/bottom` (0 = no page). The header is written with its keys sorted, so all `JSesh_page_*` entries are next to each other. A document with a page is always saved in the `.gly` dialect, since `.hie` has no header.
- The editor draws the page frame and the usable area, and a page prevails over "wrap to window".
- JS port: same model, tested against the Java `paged` layout fixture.

## Done 20261104 (automatic pagination)

- A page with a height (`PageSpecification.isPaginated()`) cuts horizontal text into pages. Pages are stacked in the view, `pageStride() = pageHeight + PAGE_GAP` apart. A line which would cross the bottom margin goes to the top of the next page (unless it is alone on its page); `!!` starts a new page. See `LineLayout.avoidPageBottom`, mirrored in `layout.ts`.
- The editor draws one frame per page. `SelectionExporter.exportToPages` lays the text out once and draws each page clipped (PDF uses the page's margins instead of the forced 32pt).
- Not paginated: vertical text (`ColumnLayout`), zones, and a page with no height (then `!!` keeps its old meaning).

Done: a "Pagination" dialog (File menu, after "Document Properties": on/off check box, standard size or custom size, orientation, margins, length units). With "respect text layout" (now the default), the PDF export of a paginated document uses the document page size; the PDF format menu is then disabled.

Still to do: keeping a line and its following lines together (widows/orphans), page-size-dependent content in margins.

The unused `JSesh_text_origin_x/y` and `JSesh_text_width/height` constants of `JSeshInfoConstants` were removed (nothing read or wrote them; the page margins replace them).
