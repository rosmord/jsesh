# Factorise what can be factorised in model types

created
: 20261020

We have limited the coupling between most of our packages. There is no **code** coupling between the parser and the model (but of course, there is a logical coupling, as they describe the same thing). This being said, this comes at a price: we repeat a lot of code. In some cases, the elements are genuinely different : most model elements are observable and mutable for instance. In other cases, in particular in the case of constants (e.g. the direction of an insert) this code duplication is somehow artificial.
