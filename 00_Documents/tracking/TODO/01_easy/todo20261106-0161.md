# Flatten some useless sub-quadrats

created
: 20261106

- If possible, treat `x*(a*b)`, `a:(b:c)`. as `x*a*b`, `a:b:c`;
    - during edition, at least in the case of `a:(b:c)`, the sub-quadrat might be needed to create `a:(b:c)*t` (for instance).
    - but it should look as `a:b:c` in the layout
    - when saving the document, it should be saved as `a:b:c`.
