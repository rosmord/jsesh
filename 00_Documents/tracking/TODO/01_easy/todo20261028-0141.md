# Dialog for zone settings

created
: 20261028

The editor can create a zone (Text ▸ Put in a Zone), but its settings (`layout`, `dir`, `width`, `height`, `lineskip`, `colskip`, `frame`) can only be changed by editing the MdC text.

Add a dialog to edit the `ZoneParameters` of the zone around the cursor, as an undoable model operation.
