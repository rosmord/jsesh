# Tabbing support

created
: 20261028

Add support for tabbing, in the TeX/LaTeX way.

- tabbings should allow one to define tab stops
- tab stops would be local to a %zone
- tab stops will dynamic (as in LaTex). I.e. they will move to acccomodate the length of the text between them. The idea is that the can be used for critical editions.
- tab stops will be defined by using special operatators; we need to think about them
- they will work in line or in column layout.


### 2. Tab stops (0060)

- horizontal and/or vertical;
- control possibly over the whole page (or a zone, once that works);
- control of the alignment between two tab stops: space on the left, space on the right, or justification;
- keep the "?" behaviour from Winglyph (to be checked);
- possible syntax:

  ~~~text
  Code: %[label=1,justification=fill,orientation=h]
  ~~~

  (nice CMYK red for reference: 0 52 62 7)
- by default, the orientation is contextual;
- the label is mandatory;
- the scope of the justifications is to be decided later;
- an EXPLICIT page break certainly clears the tab stops, and so does `%[clear]`.
