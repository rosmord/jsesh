# Add file associations for linux and Windows

created
: 20260821

Currently, JSesh does manage file associations for Mac OS X, but not for Linux and Windows.

The system is different for Mac OS X, as it uses a specific mechanism. Linux and Windows use, if I understand well, the command line arguments of the `main` function.

So, this would entail:

1. add a support for arguments in the `main` function of `JSeshAppli`
2. configure the installer to manage the file association.
