# Port %zone to the JavaScript port

created
: 20261028

`%zone[...](...)` is implemented in Java (model `Zone`/`ZoneContent`/`ZoneParameters`, layout in `Layout.visitZone`/`visitZoneContent`, drawing in `DefaultElementDrawer.visitZone`). The JS port still drops zones in `mdcreader/builder.ts`, so the fixture cases `%zone(A1)` and `%zone[id=1](A1)` now fail in `writer.test.ts` and `layout.test.ts` (14 tests).

To do in `jsesh-js/packages/core`:

- model: `Zone`, `ZoneContent`, `ZoneParameters`;
- `mdcreader/builder.ts`: build them (options `layout`, `dir`, `width`, `height`, `lineskip`, `colskip`, `frame`);
- writer: `%zone[...](...)`, toggles closed at the zone's limits;
- `render/layout.ts`: the zone's own context (orientation, direction, no margins, not paged, wrap width), `visitZone` sizing and `deltaBase`, per-view orientation;
- `render/svg.ts`: frame.

Wrapping (todo 0001) should be ported first, as `width=` relies on it.
