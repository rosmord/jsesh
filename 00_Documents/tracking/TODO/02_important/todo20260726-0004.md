# Move PossibilitiesList creation into the widget workflow

created
: 20260726

Outsource the creation of `PossibilitiesList` to something more closely linked with the widgets workflow.

Note that those lists depend on the available signs, i.e. on the glyph
configuration.

- currently `HieroglyphDatabase` has many methods which are quite dependent on the widget workflow;
- it would move much of the code about `PossibilitiesList` out of the database.
