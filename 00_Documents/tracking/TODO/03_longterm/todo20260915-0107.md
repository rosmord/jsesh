# Add a way to change font size in the user interface

created
: 20260915

Font size in the user interface is fixed. As a result, on some screen, it can become quite small. For instance, the size of the text in the "MDC" textfield, which many users use to edit the text (in particular non-hieroglyphic text), might be changed by users.

Source: https://github.com/rosmord/jsesh/issues/48 (issue #48)
