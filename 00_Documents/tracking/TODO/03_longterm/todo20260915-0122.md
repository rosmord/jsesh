# Change look and feel?

created
: 20260915

JSesh look and feel hasn't been modified for a while. I don't care much about themes, which I view as gadgets, but font scaling depending on screen is important.


Possible candidates for new UI themes are [radiance](https://github.com/kirill-grouchnikov/radiance) and [FlatLaf](https://github.com/JFormDesigner/FlatLaf).

BTW (mostly a note for myself), the [ephemeral](https://github.com/kirill-grouchnikov/ephemeral) design system used by Radiance seems interesting.

Source: https://github.com/rosmord/jsesh/issues/77 (issue #77)
