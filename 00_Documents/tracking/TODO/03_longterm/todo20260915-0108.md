# Modernize the parsing software

created
: 20260915

The part of JSesh which reads *Manuel de Codage* files is very old. Actually, some parts are ports from my HieroTeX packages, which is 30 years old.

The real problem is that the softwares I use to write my parser, **Cup** and **JLex,** are more than twenty years old, and use obsole Java constructs: `Vector`, no generics, `new Integer(n)` to create an `Integer`, etc.

It gives many warning when looking at the code in an IDE, but more seriously, some of those constructs might be removed from Java one day.

It would be a reasonable move to:

- port the **JLex** code to **JFlex**, which is apparently very compatible ;
- update the version of **Cup**.

Source: https://github.com/rosmord/jsesh/issues/55 (issue #55)
