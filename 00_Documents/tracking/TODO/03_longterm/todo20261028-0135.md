# Add support for line drawn fonts

created
: 20261028

It is already possible for a JSesh glyph to contain non-filled strokes, but the support is minimal.

Ideally, the lines would **always** have the same width, giving the same security Winglyph had in this respect.

To give a bit more flexibility, we could have multiple predefined line widths, say three possibilities, for wide, medium and thin lines. They would be assigned to fixed line width in SVG.

We should :

- provide a clear definition of who it works ;
- provide a way to translate the three line width into actual line width
- decide if the finer width would be displayed in very small sizes
- use more or less the algorith we use for shading to keep the line width constant when scaling the glyphs.
