# Redesign the drawing system around explicit graphic elements

Complete overhaul of the drawing system, making the graphic elements
explicit. Drawing would then become entirely mechanical: *all* of the
layout would be done in `Layout`. The link between graphic elements and
model elements would be handled through a map.

Motivation: currently, for some elements, logic is split between layout and
drawing (in particular for variable-size elements), or for graphic elements
that are not found.

Related: simplify the various "experts" (Layout/Drawing, etc.) - there is
probably no need for so much runtime configurability (why would we need to
be able to swap the drawing system on the fly?).

Also review the overall program structure, and in particular the notion of
Document.
