# Add text libraries and all licenses **in** the application

As the `jpackage` installation tools are not that powerful, the most secure and straighforward way to ensure that the text libraries and licenses are available to the user is to include them in the application itself.

For the text, the first version will contain an *extract text library* entry which will copy the texts in a folder of the user's choice; later version might contain more sophisticated uses of the library

for the licenses, a panel displaying each licence will be ok.
