*Released 2008/01/20*

this release mainly adds new signs to JSesh

* complete "C", "G", and "H" families: all the gods and birds you wanted, and more.
* a few signs have been fixed when they contained errors.
* the data on the "C" family has been completely typed, so that you can see what the palette can do. Find a god sign using one of his attributes !
* An experimental window executable installer is provided, for people with windows Vista (it also works on XP)
* A bug fix with Mac OS X Leopard, which made JSesh very slow on this system, has been made. Please tell me if it works, as I cautiously keep my Tiger.
