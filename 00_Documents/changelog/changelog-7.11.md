*Released 2025/09/05*

**JSesh 7.11 is out !**

It features a number of minor improvements, modified signs, and new texts!

## Fonts

A few signs have been fixed to match the reference fonts (including Gardiner), and others have been added, especially for Louvre C65 ; A [complete list of changes is available here](/signdiffs/release-7.11).

New signs have been drawn by:

- Luca Miatello
- Joshua Aaron Roberson;
- Serge Rosmorduc

We have documented most of those signs.

## Texts

We have added texts contributed by:

- Mustafa Bilgin;
- Nico Pollone;
- Tarek Hanafey Ahmed.

A detailled edition of the cryptographic stela [Louvre C65](https://www.qenherkhopeshef.org/encodingnotes/louvrec65), sent to me by M. Nico Pollone, has been updated to include  specific signs, drawn for the occasion.

## Improvements

If you are a programmer, you can also help by contributing to the code. [Jocelyn](https://github.com/Jocelyn1109) has recently fixed a few bugs, which is both helpful and a good way to start contributing.

- Jocelyn1109 has fixed a bug in SVG export. The *cancel* button would not work.

- Modified sign retrieval. Now, for instance, O10 has value Hwt-Hr, and can be retrieved by typing HwtHr.

**Full Changelog**: https://github.com/rosmord/jsesh/compare/release-7.9...release-7.11
