*Released 2026/07/26*

JSesh 8.0 beta is a pre-release of a major modification of JSesh. Most changes are internal, and this release is mostly a new ground for future development.


## Visible changes

- the user can explicitly choose the language of the UI (which still defaults to his system language);
- arabic localisation has been added;
- a bug in SVG export has been fixed.

## Internal changes

- The font management has been reworked;
- the preferences ("style") now use immutable objects;
- the structure of the jsesh library has been reworked, to make the package layout clearer.
