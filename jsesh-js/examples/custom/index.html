Building your own editor and palette

The same editor and palette as the other examples, but built from their lower-level parts: an EditorSession (the editing state machine, with no DOM) shown by an EditorView in a div of our own, and a PaletteController (the palette's logic, with no DOM) drawn with a few lines of our own markup. This is the starting point for a Vue or React component: see the documentation.
