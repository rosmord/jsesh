# jseshJsExport

A utility software to exports JSesh data (glyphs, sign database, labels) and golden test fixtures for the JavaScript port in jsesh-js/.

To use it, run either:

- `../gradlew exportAll` from the jseshJsExport folder, or
- `./gradlew jseshJsExport:exportAll` from the root folder of the project

It builds many files and performs quite a few tests. Hence, it's a relatively long run.
