# Text arrows

created
: 20260915

The original manuel de codage has a few codes which are not handled by JSesh :

- `^` : for extended arrows `<---->` ; 
- `?`  : lacuna 
- `??` fully lacunar line

Only the first one has survived in Winglyph and Macscribe, and is missing from JSesh.

Likewize, it would be interesting to add vertical alignment when writing in columns.

Source: https://github.com/rosmord/jsesh/issues/61 (issue #61)
