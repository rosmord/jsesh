# Add the notion of "ghost" codes

created
: 20260915

The wording might be a bit misleading here. Egyptologically, ghost signs would be signs which have been created by egyptologists, and don't really exist in the sources (e.g. V49).

Now, what I would like to do is to be able to standardize some codes.

For instance, I have at some point used Ff2, the code given by Gardiner, to a sign which is also coded as V49A.

One of those code must go, but texts encoded with it should still be usable. A solution would be to map the obsolete code to the new one.

The code might be kept in the sign list, but:

- it should not be possible to encode a text with it (ideally, using it would automatically replace it with the standard code);
- JSesh should replace the code by the correct code when loading texts which contain it.

Source: https://github.com/rosmord/jsesh/issues/65 (issue #65)
