# Add popup menu to choose signs from translitteration

created
: 20260915

It's a very old issue in fact.

Systems for ideographic writing systems (e.g. Chinese) have the same functionnality as JSesh when the spacebar is used.
But they also have the possibility to present the use with the list of possible choices in a popup menu.

I'd like to add it. In a way, what prevented me from writing it was the problem of choosing a keyboard shortcut for it, which would not be problematic regarding **any** operating system.

Source: https://github.com/rosmord/jsesh/issues/64 (issue #64)
