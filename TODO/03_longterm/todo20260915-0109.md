# Add information to the exported SVG

created
: 20260915

The colleagues of the synoptic edition of the book of the dead asks me if I can add to the exported SVG the glyph code as id.

It won't work, as ids are supposed to be unique, but:

- the idea of exporting the SVG along with additional information about the sign is interesting (mdc code, possibly Unicode code for research?)
- the idea of giving each occurrence a unique id is also interesting as once it's done you can easily reference the sign for further processing.

This would probably require extending SVG - something which can be done with the use of XML namespaces.

Source: https://github.com/rosmord/jsesh/issues/56 (issue #56)
