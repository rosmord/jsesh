# Change Sign information format to ease sharing

created
: 20261113

Currently, a user can document sign informations with the JSesh sign information application. However, it works with a single XML file and is somehow opaque.

I'd like to use a combination of markdown, jsesh and YAML instead, and :

1. add facilities to export a single sign information and send it to anyone (including the JSesh team);
2. embed the sign information editing in the main JSesh application;
3. create a web site to display, search and fetch sign informations.
