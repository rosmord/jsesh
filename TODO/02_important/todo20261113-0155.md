# Add marginalia

created
: 20261113

Inspired by a MacScribe functionality.

Add the construct :

~~~text
@marginalia[where=start,scale=80,sep=15](+lAn example text+s)
~~~

Which allows the addition of out-of line (or of column text). The text would not be used for page size computation (i.e. if one wants marginalia, it is necessary to choose inter-line or column skips accordingly).

Specifications:

pos
: `start` or `end`. `start` is the default. With start, the text will be placed **above** the main text, if the later is in line, while `end` will place it **below**. In column, `start` and `end` will place the text **left** and **right** of the main text, depending on the writing direction.

scale
: the scale of the text; 100% would be the same size as the main text;

sep
: separation from the main text, expressed in percentage of the reference quadrat height of the main text.
