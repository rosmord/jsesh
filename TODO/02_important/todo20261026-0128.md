# Add ids to signs

created
: 20261026

On request, each sign in a text should have a unique id, indicated as : `A1\sid2424`. `\sid` would be a fixed prefix. The numbers would be generated by the editor. No two signs added should have the same id. The ids would be used for external quotation of texts. 

They should preferably survive inplace edition of the text. That is: exploding `p\sid2*t\sid3:pt\sid4` should give `p\sid2*t\sid3-pt\sid4`. But copy/pasting `p\sid2*t\sid3:pt\sid4` should give to the pasted text new ids.

In case of direct MdC edition:

- if the text has signs ids, the edited (lines) should get new ids;
- if the text has no sign ids, the edited lines, if they contain ids, should lose them.

The text header should contain the max id.
