# Wrap columns in zones

created
: 20261028

`ColumnLayout` has no wrapping. For a zone in columns, `height=` is therefore only a fixed extent: the columns don't wrap at it, as lines wrap at `width=`.

Add wrapping to `ColumnLayout` (the counterpart of `LineLayout.wouldOverflow`/`wrapLine`), and set the wrapping height in `Layout.zoneRenderContext`.
