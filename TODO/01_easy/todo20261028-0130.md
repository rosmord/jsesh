# SVG sign embedding

created
: 20261028

Add the possibility to embed user-made SVG signs in a document.

- the sign SVG will be stored in the document header;
- the sign will have an automatically generated name, which should not be similar to a Gardiner code;
- the user will be able to state that the sign is a variant of a given Gardiner code, and perhaps to write a small description
- if the user has associated a sign with a Gardiner code, searches for this code will find the sign
- a small window can be opened to show text-specific signs, allowing the user to select them, see their code, and possibly edit their description.
- when editing the text:
  - the possibility list for the Gardiner code will include the user-made sign,
  - the codes will given by the system will be short and easy to type
- an export menu will allow to get individual SVG files for the user-made signs, for possible addition in regular fonts.
