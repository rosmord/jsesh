# Size groups

(also, deleted todo 0133 which overlapped with this one)

created
: 20261029

A mix from an idea of the Rosette project and stuff found in some GUI layout, like MigLayout.

It would be nice to be able to force some elements to have the same size, by giving them a “size group attribute”. It's in particular useful for cartouches, and enclosures in general.

The Rosette project had defined a way to add a "same-size" property to cartouches, so that they would all have the same size. This is a good idea, and we should implement it in JSesh.

The syntax might be something like:

```text
<-ra-ms-sw->[sgroup=a]
```
