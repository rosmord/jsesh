# Very large zone display is not efficient

created
: 20261115

It seems that when rendering a large zone, everything is rendered. As a result, if we have a large right-to-left document, and we decide to :

- leave the title as left-to-right, out of any zone
- put the rest of the document in a right-to-left zone

The rendering will be very slow.

Of course, we might:

- set the document to right-to-left, and
- render the title in a left-to-right zone
- leave the rest of the document as-is.

Another option is to make each page a zone (which makes sense anyway, esp. regarding tabs)
