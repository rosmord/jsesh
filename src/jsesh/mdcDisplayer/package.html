An application which will ultimately be a complete Manuel de codage source editor. Currently, it only display texts. Just for the record, you will find the following programs :
  • jsesh.dicodb.TestDessinateur : an example of use of the library to generate png pictures, suitable for web on-the-fly generation with jsp.
  • jsesh.mdcDisplayer.swing.mdcDisplayerAppli : a program to view (and ultimately edit) mdc files.
